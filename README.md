# Vortex Retro Camera

**Retro Camera by Vortex** — aplicativo Android nativo (Kotlin), com simulações fotográficas analógicas e digitais dos anos 1990–2000.

O desenvolvimento inicial será proposto em uma branch e um pull request. Status: alpha; módulos Foto e Pro experimentais, Panorama e Vídeo planejados.

Sem PWA, backend ou acesso à internet.
